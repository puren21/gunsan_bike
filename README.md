# 군산시 자전거도로 지도 — GitHub Pages 배포판

2026-10-20 업데이트: 노선의 기준 저장소는 Supabase의 gunsan_bike_datasets입니다. 도로목록 → 공용저장소에서 기존 편집 계정으로 로그인한 뒤 저장하면 도형·속성이 공용 DB에 반영됩니다. 다른 컴퓨터는 새로고침해 최신 노선을 읽습니다. 익명 사용자는 읽기만 가능하며 버전 충돌 시 덮어쓰기를 거부합니다. 이전 버전은 gunsan_bike_history에 보관합니다. roads.geojson은 연결 실패 시 표시하는 기본 자료입니다. 브라우저 백업은 저장 실패 시에도 남깁니다. 아래 과거 브라우저 저장·GitHub 반영 설명은 현재 기본 저장 동작에 적용되지 않습니다.

## 배포
1. GitHub에서 새 공개 저장소 `gunsan_bike`를 만듭니다.
2. 이 ZIP을 압축 해제합니다. **index.html이 저장소 최상위에 위치하도록 폴더 안의 파일과 road_width 폴더를 업로드**하고 main 브랜치에 커밋합니다. ZIP 자체를 업로드하지 마세요.
3. Settings → Pages → Build and deployment → Source에서 Deploy from a branch를 선택합니다.
4. Branch는 main, 폴더는 /(root)를 선택한 뒤 Save를 누릅니다.
5. 게시 완료 후 `https://사용자명.github.io/gunsan_bike/`에 접속합니다. puren21 계정이라면 `https://puren21.github.io/gunsan_bike/`입니다.

공식 안내: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 카카오 지도 설정
기존 사이트의 JavaScript 앱 키를 유지했습니다. 기존 앱 소유자가 아닌 경우 본인 앱 키로 바꾸세요.
카카오 개발자사이트에서 JavaScript SDK 도메인에 `https://사용자명.github.io`를 등록해야 합니다. 같은 puren21.github.io 도메인에서 기존 키가 허용되어 있다면 그 설정을 이용할 수 있습니다.
다른 키를 쓰면 index.html에서 `appkey=` 뒤의 기존 키를 **2곳 모두** 교체합니다(메인 지도와 로드뷰).
로컬 확인에는 웹 서버가 필요하며, 해당 localhost 도메인도 카카오 앱에 등록되어 있어야 합니다. HTML 파일을 직접 더블클릭하는 방식은 지원하지 않습니다.
공식 안내: https://apis.map.kakao.com/web/guide/

## 변경 내역
- 제목: 군산시 자전거도로 현황, 기본 중심: 위도 35.9677 / 경도 126.7366.
- 초기 개요 화면은 기존 동작처럼 제공된 경계 전체를 화면에 맞춥니다(도서 지역 포함).
- roads.geojson: 업로드 원본과 동일한 내용. 비응항로1R / 비응항로1L의 2개 지물입니다. 군산시 전체 자전거도로 데이터가 아닙니다.
- 기존 노선번호 대신 `자전도로명`을 읽어 목록·검색·지도 라벨에 표시합니다.
- Township Boundary.geojson: 업로드 동경계 63개 지물을 EPSG:5179에서 EPSG:4326 경위도로 변환했습니다. 원본 속성은 유지했습니다.
- City Boundary.geojson: 제공된 동경계를 통합한 파생 경계입니다. 별도로 제공된 공식 시경계 자료는 아닙니다.
- 경주시 엠블럼은 자전거 기호로 교체했습니다.
- 기존 지도/스카이뷰, 로드뷰, 검색, 목록, 경계 선택, 스타일, 측정, 편집, 메모 기능 코드를 유지했습니다.
- 같은 도메인의 기존 경주시 지도와 저장 설정·편집내용이 섞이지 않도록 브라우저 저장 키를 분리했습니다.
- GitHub 저장 기능은 현재 GitHub Pages 주소의 계정·저장소를 대상으로 합니다(main 브랜치). 사용자 지정 도메인 또는 로컬에서는 index.html의 GYEONGJU_GITHUB 설정을 직접 조정해야 합니다.

## 제공되지 않은 데이터와 표시 주의
- 경주시 시도·리경계·실폭도로 데이터는 포함하지 않았습니다. city_roads.geojson 및 Ri Boundary.geojson은 빈 레이어이며, road_width/index.json도 빈 색인입니다. 메뉴는 유지되지만 군산시 자료를 넣기 전까지 해당 데이터 표시는 나오지 않습니다. 실폭도로를 이용한 자동 폭 보정도 제공할 수 없습니다.
- 개설·미개설·계획구간 분류와 자동 판정을 사용하지 않습니다. 자전거도로는 6가지 도로 구분으로 표시합니다.
- 도로를 보기 쉽게 확대하거나 도로목록에서 비응항로1R/1L을 선택하세요. 전체 경계 개요 축척에서는 기존 축척 규칙에 따라 노선/라벨이 숨겨질 수 있습니다.

## 검증
- GeoJSON 형식, 좌표 범위, 경계 63개/도로 2개, 노선명 속성 연결 및 JavaScript 구문을 검사했습니다.
- 실제 GitHub Pages 배포 화면에서 카카오 지도와 노선 표시, 신규 노선 입력·초안 저장·복원·분류 편집을 확인했습니다. GitHub 반영 버튼은 실제 자료를 바꾸므로 테스트 데이터를 게시하지 않았습니다.
- 원본 SHA256 및 좌표변환 내역은 DATA_INFO.json에 기록했습니다.


## QGIS 방식의 라인 편집 (2026-10-19)
1. 우상단 연필 **편집** 아이콘을 누릅니다. 라인 편집 도구가 나타납니다.
2. 지도에서 라인을 클릭해 선택합니다. Shift+클릭으로 추가 선택하며, 마우스 드래그는 일반 지도 화면 이동입니다. 선택 라인은 주황색으로 강조되고 해당 라인의 속성이 표시됩니다.
3. **그리기**: 첫 점을 클릭한 뒤 마우스를 움직이면 다음 점까지의 선이 따라옵니다. 클릭으로 점을 고정하고 우클릭 또는 그리기 완료로 마칩니다. 생성 후 속성을 입력합니다.
4. **꼭지점**: 네모 꼭지점을 드래그해 이동합니다. 선 위를 클릭해 꼭지점을 추가하고, 꼭지점을 우클릭해 삭제합니다. 모든 꼭지점과 선분은 12px 이내에서 스냅됩니다.
5. **자르기**: 선택 라인을 가로지르는 절단선을 그린 뒤 우클릭 또는 자르기 실행을 누릅니다. 분할된 라인은 속성을 복사하고 서로 다른 라인 ID를 갖습니다.
6. **병합**: 다중 선택 도구로 여러 라인을 클릭한 뒤 병합합니다. 첫 선택 라인의 속성을 사용합니다. 연결된 끝점만 합치며 떨어진 라인은 임의의 연결선을 만들지 않고 MultiLineString으로 보존합니다.
7. **실행 취소 / 다시 실행**: 도형·속성·라인 생성·삭제·자르기·병합의 변경을 저장 전까지 되돌릴 수 있습니다.
8. **저장**: 도형과 속성을 함께 저장하고 편집을 계속합니다. **편집 아이콘을 다시 누르거나 저장 후 편집 끄기 / ×**를 누르면 저장 후 편집을 종료합니다. 잘못된 입력이나 저장 실패가 있으면 편집 모드를 유지합니다.

저장 위치는 **현재 브라우저**입니다. 새로고침 후 저장한 라인과 속성을 복원합니다. 전체 사이트에 적용하려면 저장 위치 및 사이트 반영 → GitHub 토큰 → 저장 후 GitHub에 반영을 사용합니다. GeoJSON 다운로드도 지원합니다.

단축키: Ctrl/Cmd+S 저장, Ctrl/Cmd+Z 실행 취소, Ctrl/Cmd+Shift+Z 다시 실행, Delete 선택 삭제, Esc 현재 도구 취소. Shift+클릭은 다중 선택입니다.

도로 구분은 전용도로 / 전용차로 / 우선도로 / 겸용도로(분리) / 겸용도로(비분리) / 기타입니다. 개설·미개설 판정은 사용하지 않습니다.

자르기·병합 기하 계산은 tests/bike-geometry.test.cjs의 19개 자동 검사를 통과했습니다.

| 전용차로 | 청록 | #159EA6 |

| 겸용도로(비분리) | 파랑 | #355FCC |

스카이뷰에서는 같은 색 계열의 밝은 색을 사용합니다. 편집 선택은 분류 색상을 유지하고 흰색 테두리로 구분합니다. 도로 구분 변경 시 색상은 즉시 미리보기로 반영하며 저장 전에는 공용 DB에 쓰지 않습니다. 기존 기본 색상은 갱신하며 사용자가 직접 바꾼 색상·선 두께는 유지합니다. 첨부 범례의 ‘향후계획’ 색은 기존 ‘기타’의 짙은 회색에 참고했고, 도로 구분명은 기존 6종을 유지했습니다.

편집 도구는 왼쪽 도로목록 아이콘과 같은 34px 버튼으로 표시하며, 이름은 마우스를 올렸을 때 툴팁으로 확인합니다.

공통 스냅: 그리기·선 나누기·꼭지점 이동 및 추가에 꼭지점/선분 스냅을 적용합니다. 편집 도구 아래 체크박스로 켜고 끄며 설정은 현재 브라우저에 유지됩니다. 스냅 위치는 분홍색 원으로 표시됩니다.

라인 연결: 2개 이상의 연속 라인을 선택하면 현재 연결 체인의 양 끝과 나머지 라인의 가장 가까운 끝점을 순차적으로 이어 직선 연결 구간을 미리 표시합니다. 연결 실행으로 하나의 LineString을 만들며 첫 선택 라인의 속성을 유지합니다. 실행·저장 후에도 연결 도구를 유지하고 × 닫기로 종료합니다. 실제 공용 저장은 저장 버튼으로 수행합니다. 여러 부분으로 떨어진 MultiLineString과 닫힌 라인은 연결 대상으로 사용할 수 없습니다.

도구 추가 옵션은 독립 창으로 표시하며 다른 도구 전환 시에도 유지합니다. 고정 버튼은 창 위치 이동을 잠그고 다음 접속 시 창을 복원합니다. 크기는 가장자리에서 조절하고 끄기 ×로 해당 옵션 창만 닫습니다. 지도 초기 위치·확대·일반지도/스카이뷰는 각 브라우저의 마지막 화면을 복원합니다.
